# Art for upload

Images the game needs, kept here as the source of truth. **The game cannot load these files directly**: each one must be uploaded to Roblox (Studio: Asset Manager > Import, or the Creator Dashboard), pass moderation, and get an asset ID. The IDs then go into one config file (`src/shared/config/Icons.luau`, created when the first icon is wired in). Until an icon has an ID, the game uses its code-built fallback.

## Folders

| Folder | Contents |
| --- | --- |
| `icons/` | Final in-game icons: transparent PNG, 256 x 256, file names exactly as listed below |
| `marketing/` | Roblox game page images: icon and thumbnails |
| `source/` | Editable originals (for example .psd, .kra, .afdesign, .svg). Optional; if files get large (over ~50 MB), consider Git LFS |

## Style (Diner Sticker)

Thick white "sticker" outline around each icon, a solid ink-brown (`#3d1f1f`) offset shadow, flat fills from the palette in the main README (ketchup `#e63946`, mustard `#ffb703`, teal `#2a9d8f`, cream `#fff4dc`, grape `#7b2cbf`, blueberry `#1d6fd8`, orange `#f77f00`). Keep 16 px of empty margin inside the 256 x 256 canvas so outlines are not clipped. Icons must read clearly at 32 px.

## Notes on the current set

- `star.png` is white on purpose: set the ImageLabel's `ImageColor3` to the rarity colour, so one upload covers every rarity.
- `gem.png` uses grape, matching the rebirth button that earns gems.
- The thumbnails use placeholder smiling fries for pets; swap in real pet art once the pets are redesigned.
- All of these are generated by `source/build_art.py` (Python: `pip install cairosvg pillow numpy scipy`, plus the Luckiest Guy font). Run `python art/source/build_art.py` from the project root to rebuild them. `source/icons/*.svg` holds each icon's editable vector art before the sticker border and shadow are added.

## Not needed as images

Panels, buttons, chips, progress bars, text, and layout stay code-built. Pet portraits in the panels will render the 3D pet models live (ViewportFrames), so they need no uploads.

## When adding an image

1. Save it in the right folder with the exact file name above.
2. Upload it to Roblox and wait for moderation.
3. Fill in its Status (Uploaded) and Asset ID here, and add the ID to `src/shared/config/Icons.luau`.
4. Keep the PNG here even after uploading, so it can be re-uploaded or edited later.
